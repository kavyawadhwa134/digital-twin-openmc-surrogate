# Machine-Learned Surrogate Modelling for Reactor Neutron Transport

Code accompanying a study that inserts machine-learning surrogates into the
standard two-step method of reactor core analysis and validates the full
pipeline against direct continuous-energy Monte Carlo. Demonstrated on
light-water lattices (pin cell, 7x7 assembly, 3x3 colorset core) and on a
sodium-cooled fast MOX pin cell. Also includes HUX, a hash-indexed
unionized cross-section lookup that accelerates the XSBench kernel
bit-exactly, and a digital-twin demonstrator with an LSTM state estimator.

Kavya Wadhwa, Pandit Deendayal Energy University.

## Headline result

On a 3x3 checkerboard colorset benchmark: direct continuous-energy Monte
Carlo gives k = 1.30930 +/- 52 pcm in 210 s; the ML pipeline (two
surrogate queries plus a two-group finite-difference diffusion solve) runs
in 27 ms with a maximum assembly power error of 1.30%. Error decomposition:

- diffusion with reference OpenMC constants vs Monte Carlo: **-306 pcm**
- diffusion with ML surrogate constants vs Monte Carlo: **-212 pcm**
- error added by the ML surrogate: **+94 pcm** (0.02% max in power shape)

Every accuracy in the project is reported on a held-out test set against
the Monte Carlo statistical noise floor of the training labels, not R^2.

## Environment

```bash
conda env create -f environment.yml
conda activate openmc
export OPENMC_CROSS_SECTIONS=/path/to/endfb-viii.0-hdf5/cross_sections.xml
```

Core dependencies: OpenMC 0.15.1 with ENDF/B-VIII.0, NumPy, SciPy,
scikit-learn, PyTorch, and CuPy (optional, for the GPU HUX benchmark).

## Scripts

Run everything from the project root after activating the environment.

### Data generation (OpenMC)

| Script | Purpose |
|---|---|
| `scripts/run_pincell_sweep.py` | 700 LWR pin-cell cases (LHS over eight state parameters). |
| `scripts/run_assembly_sweep.py` | 500 heterogeneous 7x7 assembly cases; extracts 14 two-group constants + k_inf. |
| `scripts/run_sfr_pincell_sweep.py` | 150 sodium-cooled fast MOX pin-cell cases with the two-group boundary at 0.1 MeV. |
| `scripts/run_core_colorset.py` | Reference direct Monte Carlo on the 3x3 checkerboard colorset. |
| `scripts/simulate_reactor_dynamics.py` | Point-kinetics + two-node thermal-hydraulics transient generator for the digital twin. |
| `scripts/generate_state_sequences.py` | Labelled sliding-window state sequences for the LSTM. |
| `scripts/extract_xs_dataset.py`, `scripts/extract_macro_xs_dataset.py`, `scripts/extract_xs_resonance_dataset.py` | Cross-section extraction utilities. |

### Surrogate training and evaluation

| Script | Purpose |
|---|---|
| `scripts/train_pincell_surrogate.py` | LWR pin-cell surrogate (k_eff and multiphysics outputs). |
| `scripts/train_assembly_surrogate.py` | Assembly group-constant surrogate (14 constants + k_inf). |
| `scripts/train_sfr_pincell_surrogate.py` | SFR fast pin-cell surrogate (identical leakage-free protocol as the LWR case). |
| `scripts/train_lstm_forecaster.py` | LSTM state forecaster; MC-dropout uncertainty with per-signal variance recalibration. |
| `scripts/train_state_forecaster.py` | Alternative twin state forecaster. |
| `scripts/evaluate_pincell_surrogate.py` | Pin-cell evaluation utilities. |
| `scripts/evaluate_digital_twin_robustness.py` | Coverage, physics residual, fault classification. |
| `scripts/combine_assembly_datasets.py` | Merge multiple assembly sweeps into one dataset. |
| `scripts/diagnose_assembly_overfit.py` | Train-vs-test/learning-curve/noise-floor diagnostic. |

### Core pipeline closure

| Script | Purpose |
|---|---|
| `scripts/solve_core_pipeline.py` | Two-group finite-difference diffusion solver driven by the surrogate; produces the 3x3 power map and the +94 pcm error decomposition. |

### HUX cross-section lookup

| Script | Purpose |
|---|---|
| `scripts/xs_lookup_harness.py` | Fair CPU benchmark: per-nuclide binary search, unionized grid, hash-indexed unionized (HUX). Bit-exact accuracy gate. |
| `scripts/xs_lookup_gpu.py` | The same three methods on GPU via CuPy (fp64 and fp32). |
| `scripts/benchmark_xs_surrogate.py`, `scripts/benchmark_macro_xs_surrogate.py` | XS surrogate timing benchmarks. |
| `scripts/train_xs_surrogate.py`, `scripts/train_xs_surrogate_torch.py`, `scripts/train_macro_xs_surrogate_torch.py` | Alternative XS-value surrogates (the value-predicting neural network shown to be inadequate in the resonance region). |
| `cuda_xs_benchmark/` | Portable, self-contained copy of the GPU benchmark for a CUDA host. |

### Figures

## Reproducibility

- OpenMC 0.15.1 with ENDF/B-VIII.0 (556 nuclides available).
- Random seeds are fixed and leakage-free splits are used throughout;
  the held-out test set is touched exactly once per surrogate.
- Lookup timings are measured serially on CPU and on an NVIDIA GTX 1080 Ti.
- Surrogates in scikit-learn; digital twin in PyTorch; GPU kernels in CuPy.
